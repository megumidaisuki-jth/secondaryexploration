# 资源匹配下超图支付网络的服务可靠性 删繁修订版

修订日期：2026-10-12。基于2026-10-10作者稿；旧版保留，本版不是新实验。

主稿PDF为10页双栏版，Word为15页单栏可编辑版；补充PDF10页，Word9页。main.tex和supplement.tex为排版源文件。

changes.md与changes.json保存逐项原文和修订；concision-checks.json保存内容保全检查；word-checks.json保存原生数学及图表转换核验；qa.md记录渲染检查。editorial-notes.md说明删留标准和未完成的投稿准备事项。

figures保留11份原矢量图；source-data保留9份统计与验证JSON。word-figures仅用于Word预览，不能代替矢量图。manifest.json绑定本版本载荷；source-package.zip包含稿件和源资产。该便携包不重复复制大型原始模拟区块和检查点，其仓库位置保持不变。

verify_concision.py可用项目环境执行只读重检，默认使用check子命令：python verify_concision.py check。封存后word与seal子命令拒绝覆盖，需另开修订版本。
