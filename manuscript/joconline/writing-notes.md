# 中文稿编写与证据说明

日期：2026-09-29。目标期刊：《通信学报》。本稿为作者可修改的完整中文初稿。

## 一句话论证

在固定资金、参与关系及协议的合成超图支付网络中，以首次全局无路径为服务事件，4类构造相对于各自二元参照的可靠性效应在独立相位中复现，同时存在更高的多方协调暴露量。

## 结构及写法

引言采用应用问题—技术瓶颈—已有路径—具体缺口—贡献的顺序。全文按相关工作、模型、资源匹配与构造、实验设计、结果、讨论、结束语组织。参考近年期刊文章的技术性写法及问题—方法—验证的摘要组织，不复用其句子或科学主张。用户明确要求中文，覆盖 nature-writing 的默认英语输出约定。

格式依据为期刊官网 https://www.joconline.com.cn/zh/info/15279/ 和 https://www.joconline.com.cn/zh/info/15278/ （2026-09-29核查）：中英文前置材料、中文题名不超过20字、中文摘要不超过200字、至少4个关键词、五号宋体正文、可编辑公式、中文黑白图表、三线表和顺序编码参考文献。官网正文模板下载链接是动态页面，本次未取得可用原始Word模板；Word稿按公开条目重建为通栏投稿稿，不冒充出版社终排模板。版式与官方模板原文件的逐项比对留作投稿前检查。

文体参考：2025年46卷6期45–59页《基于并行流量图和图神经网络的加密流量分类方法》，官方摘要与PDF入口 https://www.joconline.com.cn/zh/article/doi/10.11959/j.issn.1000-436x.2025095/；2024年45卷Z1期97–104页《基于区块链的支付信道网络：挑战与发展》，https://www.joconline.com.cn/zh/article/doi/10.11959/j.issn.1000-436x.2024217/ 。参考的是体裁与组织方式，不声称对其全文完成逐句语体分析。

## 术语约定

| 中文术语 | 对应定义 | 处理 |
|---|---|---|
| 超图支付网络 | hypergraph payment network, HPN | 与既有术语表一致 |
| 首次无可用路径 | tau_nopath | 全局可行路径集合为空，不是K候选搜索失败 |
| 首次余额耗尽 | tau_dep | 任一方向性余额首次为0 |
| 归一化受限无路径时间 | min(tau_nopath,H)/H | 请求时钟、含删失，不称无限寿命 |
| 固定时域失败风险 | P(tau_nopath≤H) | 不等于全部请求的失败比例 |
| 参与关系预算 | 各超边大小之和 | 奇数预算使用上下两个二元参照 |
| 独立确认 | 两相位均通过相应区间与门控 | 不等于两相位合并推断 |
