# 通信学报作者修订稿 v1（2026-10-10）

本版从已封存的 `../joconline-integrated-v1` 派生，针对投稿前审查作编辑性修订，不是新实验或独立科学盲审。原版本及全部科学输入保持不变。

## 文件与用途

- `main.tex` / `main.pdf`：双栏作者排版主稿，11页；不是出版社官方模板。
- `supplement.tex` / `supplement.pdf`：S1–S5补充分析，10页。
- `main.docx` / `supplement.docx`：单栏可编辑Word作者稿，17页、9页；公式为原生Office Math。页数因软件和字体环境可能变化。两栏阅读版以PDF为准。
- `figures/`：11幅原矢量PDF，逐字节复用；`word-figures/`仅为Word嵌入的300 dpi预览，不代替矢量原图。
- `source-data/`：9份已完成统计及验证JSON原样复用。完整模拟区块、检查点及计算证据仍在仓库原目录，本包不复制这些大型数据。
- `revision-checks.json`、`word-checks.json`、`qa.md`、`manifest.json`：版本范围、转换与完整性记录。
- `references.enw`：本轮新增的两篇预印本记录；并非替代正文17条完整参考文献。
- `source-package.zip`：便携作者稿包；校验清单不包含自身和压缩包，避免循环哈希。

## 本轮修订

1. 中文摘要缩至195字；英文摘要与其研究范围一致。
2. 不再把成员余额坐标和守恒更新表述为新模型；明确沿用已有多方信道研究。
3. 增补COALESCE与MaxPTE的相关工作，区分协议执行、当前余额最大流与本稿原子单路径序列首次无路径事件；不跨条件作性能排名。
4. 修正文献[11]文章页码，补充Starfish已登记期刊DOI，同时保留实际核读的修订预印本来源；不虚构卷期。
5. 保留18个编号公式、2个无编号展示公式及完整实验结果；首次引文顺序为[1]–[17]。
6. 调整文末参考文献间距，取消孤立的作者简介尾页；制作原生数学Word版本，检查全部图注。

论证主线：在声明的原子支付和完整余额路由条件下，以资金及参与关系匹配和父图分层配对推断评估多超边持续服务，并以独立相位检验受控比较的复现，报告协调代价和补充分析的否定性结果。

术语约定：PCN＝支付通道网络；HPN＝超图支付网络；DA＝需求感知构造；FHS3/FHS5＝最大规模3/5的固定规模构造；NCH＝节点覆盖构造；Y＝归一化受限无路径时间；F＝固定时域首次无路径指标。局部首次触零、首次无路径和首次拒绝不能互换。相位名表示数据来源，不使S1–S5事后分析成为新的确认性检验。

## 尚不能直接投稿的事项

- 作者署名、单位、通信作者、基金和简介仍依用户要求保留待填。
- 图稿尚未统一完成期刊指定的黑白印刷、中文字体及字号适配。尤其图S4/S5的窗口区分依赖颜色，需要无颜色冗余编码；不可直接灰度转换后宣称完成。
- 官网英文摘要长度条款写作“150个字符”，表述有歧义；当前英文摘要按空格分词为98词（含公式源标记），不宣称满足150字符。须向编辑确认后定稿。
- 正文是期刊风格作者稿，不是官方Word版式；实际投稿前应核对最新模板、篇幅及参考文献规则。
- 这是编辑修订与复用校验，不是对创新性、有限样本覆盖率或真实网络外推的证明。
