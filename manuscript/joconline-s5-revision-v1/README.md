# 四臂补充纳入版：阅读与复现

本目录单独保存正文修订，原 `joconline-latex` 的10页稿和其交付清单不变。
本版不是期刊官方模板；作者、单位、邮箱及基金继续待填。

- `main.tex` / `main.pdf`：原双栏作者稿加入四臂设计、直接交互公式、完整初态对比图及边界讨论。
- `supplement.tex` / `supplement.pdf`：三组完整补充图及读图说明；图S1绝对均值、S2拓扑对比及交互、S3初态对比。
- `s5-main-section.tex`：已纳入正文的精简小节；`s5-section.tex`保留未精简的详细解释，方便后续写作；不改变冻结模拟代码。
- `revision-map.json`：原文与统计输入哈希、改动映射、原稿未变检查。
- `figure-contract.md`：论点、术语、面板设置、实验基础、统计定义与证据边界。
- `qa.md`：数值、导出、编译与视觉检查范围；不能替代独立科学盲审。

## 主要修订含义

保留主分析的超图—二元参照比较，不把它改写为DA搜索或资金优化的增量收益。
新增四臂小节说明：在这些已观察条件中，原优化初态并不普遍优于均匀初态。
全部80项合并范围比较均进入图S2/S3，64个合并均值进入图S1；没有筛掉不利条件。
完整432行源数据及精确分数位于 `results/supplement/initialization-ablation-figures-v1/source-data.json`，
其中128个子范围均值与160个子范围对比仍保留，不附造区间。

所有图均有PDF、SVG、PNG和600 dpi LZW TIFF。Y为无量纲值；F均值按百分数显示，
F差按百分点显示，不是相对风险百分比。每相位/规模的独立n为60父图，不是请求数或重抽样副本数。

## 复现

仓库根运行 `python -m tools.build_s5_manuscript_figures`。需要已有matplotlib及中文字体；
脚本先核验统计结果、算术核验收据及原稿哈希，拒绝静默使用改变的输入。
默认Python包路径沿用本项目已有文档运行环境。之后在本目录用已有XeLaTeX或Tectonic
分别编译 `main.tex`、`supplement.tex`。构建会重建本目录生成的TeX及图，不覆盖原10页稿。

本次没有新模拟、训练、种子、bootstrap或显著性检验。补充分析使用已查看数据，
点态95%区间未作多重比较校正，不继承主分析家族确认许可。
