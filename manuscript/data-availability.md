# Data Availability (working draft)

The 2020 and 2023 Lightning structural cross-sections were obtained from
version 1.1 of *Geolocated Lightning Network topology snapshots: A dataset
covering 2019–2023* (Harvard Dataverse,
https://doi.org/10.7910/DVN/2OAVO6), which is distributed under the Creative
Commons Attribution 4.0 International licence. The 2022 topology and
transaction trace were obtained from the public companion repository for
Kotzer *et al.* at commit
`2c4ffc92d704fa1b043fac395c1e5f662990d497`
(https://github.com/iAradK/improving-Blockchain-Scalability-with-Hypergraph-Payment-Networks/tree/2c4ffc92d704fa1b043fac395c1e5f662990d497);
because that repository does not
state an explicit data licence, those raw files are not redistributed here and
must be retrieved from the original repository. The 2026 cross-section was
captured from the Lightning Dev Kit Rapid Gossip Sync v2 service on 7 August
2026. The server software is available under MIT or Apache-2.0, but no explicit
licence was identified for generated snapshot payloads; the captured payload
is therefore not redistributed. The service's zero-timestamp URL is dynamic
and no longer constitutes persistent access to the exact historical capture.
Accordingly, the 2026 panel will remain diagnostic-only unless permission is
obtained to preserve the exact payload in a durable repository; otherwise it
will be removed from publication claims. Exact source URLs, versions,
retrieval metadata, selected archive members and cryptographic hashes are
provided in the source-rights and source-identity contracts.

The study's manifests, compact derived registries, analysis code, processed
tables and figure source data will be archived in a DOI-bearing repository
before submission. The archival DOI and licence for project-generated outputs
have not yet been assigned.
