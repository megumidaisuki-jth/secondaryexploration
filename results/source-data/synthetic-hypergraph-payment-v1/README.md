# Synthetic hypergraph payment Source Data v1

`source-data.json` is the canonical machine-readable export required by the
results reporting contract. Its content fingerprint is
`d82d90b43938efead325d1d2773f064b32e557d6776f3851c2cb7d37b0e5857d` and
its byte SHA-256 is
`50fd83d81d54cfaf7198b3307f10a51d4a1f555b94ab06975e2d3b0b3d8e30f4`.

The JSON contains both phases' complete 40-row interval registries, all 40
cross-phase replication records, 2,400 parent-model values per phase,
event-coverage and activity-sensitivity cells, 12,480 descriptive parent
values per phase, descriptive summaries, complete run summaries, source-file
hashes, and the five independent replay receipts.

Values are retained in their original JSON representation. Presentation
rounding belongs in derived manuscript displays; this file remains the source
for those displays.
