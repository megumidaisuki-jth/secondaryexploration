完成日期：2026-10-07。S1直接配对消融和S2描述性分解已完成。未新增支付模拟，未修改原稿或原冻结统计结论。

## 本次发现

新增16项比较的校正区间均包含零。现有结果不足以支持需求感知方案DA相对其FHS5种子具有稳定服务增益，也不能据此证明总体等效。

- n=30 的时间差在两相位点估计均为正，分别约0.001858和0.000906，校正下界均为0；不构成校正后的明确有利区间。
- n=60 和 n=120 的时间点估计在两相位出现方向不一致。
- n=240 的两个父图平均终点差在两相位均为0；这是样本内父图平均差的描述，不推出所有请求轨迹相同或总体等效。
- 失败风险差是绝对概率差，不是相对下降率。n=30确认相位约为−0.011905，即约−1.1905个百分点，校正上界为0。
- S2显示范围内的差异可能被总体均值抵消。例如n=120正式相位风险差，同分布均值约+0.004167、偏移均值约−0.005556，4:3合并后为0。这里只作描述，没有进行新交互或机制显著性检验。

该结果不推翻此前超图相对二元参照的已冻结结果；它回答的是不同问题：DA训练相对于FHS5种子增加了多少收益。论文可以保留需求感知构造作为有界训练方案，但不应把稳定优于种子作为未经支持的贡献。

## 方法和确认性边界

每个规模、每个相位60个独立父图，3种模型层各20个。每父图7条轨迹先平均，模型层等权。利用同一配对执行中的相同二元参照消去，恢复DA−FHS5精确差值；所有配对身份、参照、时域检查通过。未排除样本、未插补数据。

S1使用20000次父图分层聚类bootstrap，两个终点共用抽样索引。2相位×4规模×2终点共16项组成新的后验探索家族。Bonferroni单区间名义99.6875%，家族名义95%；每侧尾概率1/640，取有序样本第32和19969项。另存未校正95%区间，取第500和19500项，但不用于本报告的校正方向判断。使用精确整数分子和有理数，无浮点临界值判断。

百分位bootstrap不保证有限样本精确覆盖，尤其稀疏非零差异和退化经验分布下需谨慎。没有计算p值，没有使用原40项比较的门控，也没有把后验分析冒充预注册确认性实验。

S2包含32项范围均值和112项完整机制均值，仅描述，不增加显著性结论。所有16个范围4:3重组与S1点估计精确一致。
