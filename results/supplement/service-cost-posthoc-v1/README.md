# S3 服务量与成本联合分析

日期：2026-10-07。复用正式与确认相位各240个已保存父图区块；没有新增支付模拟。本次补充为后验探索性分析，保留原论文冻结结果。

## 核心发现与论文解释

四个规模、四个超图方案和两个相位形成32个源方案—匹配二元参照单元。全部32个单元的点估计表现为：单位成功支付的超边遍历次数更少，但参与者信令槽、路线内去重参与者、平方协调暴露和arity-log₂暴露更高。这是样本内描述，不是对全部总体比较作出的同时显著性声明。

因此，论文可以讨论“更少的路线遍历与更高的多方参与暴露之间的权衡”，但不能将超边跳数缩短等同于通信成本降低。模型暴露也不能换算成真实协议中的延迟、字节数、交易费或密码学运行时间。

例如，正式相位 n=240、DA与其资源匹配二元参照的描述性均值如下。每组60个独立父图，三模型层各20，父图内7条轨迹等权。

| 指标 | DA | 对应二元参照 |
|---|---:|---:|
| 成功率 | 99.9922% | 96.2607% |
| 遍历次数/成功请求 | 2.476409 | 4.363149 |
| 参与者信令槽/成功请求 | 12.019947 | 8.726298 |
| 平方协调暴露/成功请求 | 59.107586 | 17.452597 |

DA相对FHS5的成本差幅度较小，并非各规模、相位和成本方向全部一致。S3不改变S1的结论边界：现有直接消融结果不支持将DA稳定优于FHS5作为核心创新，也没有证明总体等效。

## 分析口径

保存成功请求数S、成功支付总额V和五种路线成本C。每次尝试成本为E[C]/H，成功率为E[S]/H；单位成功请求成本为E[C]/E[S]，所有均值采用同一父图/模型权重。它不是E[C/S]，也不是单位成功金额成本。二元面板的多个注册臂先等权平均，再参与父图汇总和求比值。

成本分别为：遍历超边次数；Σ|e|参与者信令槽；每条成功路线的参与者并集大小再求和；Σ|e|²协调暴露；Σ|e|log₂|e|敏感性暴露。前四项及服务点估计保留精确有理数，log₂敏感性暴露和区间使用float64。成功量和成本均统计完整H=12n时域；首次失败不等同于后续所有请求停止。

每个规模和相位使用20000次模型分层父图bootstrap，所有方案、服务量和成本共享抽样索引，并在每次抽样后重新求比值与配对差。百分位区间为点对点未校正95%，第500和19500个有序值，无插值。共320个绝对比值及200个配对差；这些区间不是同时置信区间，不据此作新确认性优越性决策或挑选“显著”方案。

全部64个方案角色单元均无零服务轨迹面板或零服务父图面板，本次没有未定义的比值复制。程序仍明确记录零分母：报告null并保留频数，任何未定义bootstrap复制都会使该单元区间不可报告，不会悄悄删去复制或填0。

## 可复用文件与断点

- report.md：统计量推导、64个绝对角色单元、200项配对成本差、完整图注和局限。
- results.json：成功服务、总成本/尝试、比值、区间、精确分数、静态资源与零服务频数。
- parents/：480个小型区块提取断点及SHA-256。保存每条轨迹各物理方案的绝对服务、成本、arity histogram、资金、配对身份和原始字节哈希；原始支付模拟可继续复用。
- bootstrap/：320个500复制计算块，保存16万组所有方案服务—成本共同抽样和哈希元数据。
- verification-checkpoints/：逐区块算术复核收据和8个bootstrap单元复核收据，复核本身也可恢复。
- binding.json、progress.json、verification-progress.json：输入/代码/运行时绑定及分阶段进度；不同阶段的百分比不混为一个虚假总百分比。
- verification.json：另一套路线累加与抽样求和实现的全量复核结果。它是同一分析者的数值交叉检查，不是新的独立盲审或路径搜索重放。
- verification-v1-failure.json及存档v1核验源码：保留最初固定绝对浮点阈值不足的检查记录。v2对log₂累计和采用非负求和的gamma160误差界，整数列仍逐复制精确相等；最大相对差约1.37×10⁻¹⁵，全部16万次复制重新复核通过。未修改主计算值或重复支付模拟。
- figure-s3-arms.csv、figure-s3-contrasts.csv、parent-source-data.csv：64个角色单元、200项配对差及3840个父图×角色均值的图表底表。
- figure-s3-service-cost.svg/pdf/tiff/png：服务成功率与单位成功信令成本的联合展示。
- figure-s3-paired-cost.svg/pdf/tiff/png：遍历、信令与平方协调暴露的配对森林图。
- delivery-manifest.json：全部新增源码、配置、断点、数据和图形的字节数与SHA-256清单。

## 运行与暂停

配置为configs/supplement/service-cost-posthoc-v1.json。主入口tools/supplement_service_cost.py，算术复核入口tools/verify_supplement_service_cost.py，表图生成入口tools/report_supplement_service_cost.py。运行时版本固定在binding.json；后续改变版本或代码需建立新分析版本，不静默覆盖本版本。

创建输出目录的PAUSE文件请求在下一个父图区块或500复制块边界暂停；算术复核也在父图区块或规模/相位单元边界保存后暂停。确认进度状态已显示paused-safe-checkpoint、相关进程已退出后可关机。恢复前明确移除自己的PAUSE文件，再运行同一入口。--stop-after-units N可用于主程序主动暂停验证。异常遗留的RUNNING.lock或VERIFYING.lock需先核对进程身份，不自动删除。

已实际在前4个区块提取后暂停，并从第5个继续。全部800个主计算单元保留，常规恢复复用已完成结果；失败或未原子落盘的单元不会冒充完成。

下一步为S4较短时域敏感性；本轮尚未执行。S5新增初始化模拟仍需单独授权。
